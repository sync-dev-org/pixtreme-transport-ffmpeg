Each wheel and SDK includes FFmpeg-LICENSE.md, FFmpeg-BUILD.txt,
FFmpeg-changes.diff and FFmpeg-configuration.json with the license information,
build instructions, applied changes and configuration for its FFmpeg libraries.
Its FFmpeg-NOTICE.txt identifies the FFmpeg version, corresponding patched source
archive and source SHA256. The source archive is provided in the same release:
https://github.com/sync-dev-org/pixtreme-transport-ffmpeg/releases

patent license terms in PATENTS accompany the wheel, SDK and corresponding source.
